    方法與限制

    1. 資料來源：民生公共物聯網資料服務平台，環境部「智慧城鄉空品微型感測器」資料集（全國約 10,999 點，更新頻率 3 分鐘，2017 年 6 月起），以 OGC SensorThings API v1.0 介接，免 API key。授權：政府資料開放授權條款第 1 版。
    2. 編號比對：輸入值會依序嘗試 properties/locationId、properties/stationID、完整 name、名稱片段四種比對；命中即停。
    3. 時區：API 的 phenomenonTime 為 UTC，本頁一律轉為台灣時間（UTC+8）後才分組與繪圖。
    4. 分頁：SensorThings API 單頁上限 100 筆，以 $skip 迴圈取回完整區間，併發上限 4。
    5. 量測品質：微型感測器多為光散射法，靈敏度與國家級測站儀器有落差，環境部明示其數據不宜直接比對空氣品質標準，只適合觀察相對趨勢與時間 pattern。高濕度下光散射法對 PM2.5 常有正偏誤。
    6. 缺值：感測器離線或回傳延遲會造成時序中斷，本頁以斷線呈現（不內插）；小時有效筆數 < 5 標記為低樣本（半透明）。
    7. 用途：個人資料探索工具，非法規依據。若要引用於論文或正式報告，應改用國家測站經品保程序後的數據。
